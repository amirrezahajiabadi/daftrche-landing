# دَفتَرچه — لندینگ پیج (Landing Page)

لندینگ پیج رسمی **دَفتَرچه**؛ یک دفترچهٔ آرام برای کارهای روزانه، تمرکز و خواندن.
شعار و هستهٔ طراحی: *«امروز قرار نیست همه‌چیز را انجام بدهی.»*

این وب‌سایت کاملاً استاتیک است (Pure HTML/CSS/Vanilla JS)؛ بدون هیچ فریم‌ورک، ابزار ساخت (Build Tool)، مدیر بسته (Package Manager) یا وابستگی خارجی. تنها با باز کردن `index.html` در مرورگر، کل سایت در دسترس است.

## اجرای محلی (Local Development)

صفحه بدون سرور هم باز می‌شود، اما برای تست صحیح مسیرهای روت در `404.html` و عملکرد دقیق سیاست CSP، اجرای روی یک سرور استاتیک محلی پیشنهاد می‌شود:

### با پایتون:
```bash
python -m http.server 8000
```
سپس در مرورگر به نشانی `http://localhost:8000/` بروید.

### با Node.js:
```bash
npx serve .
```

## انتشار روی GitHub Pages

این پروژه مستقیماً از شاخهٔ اصلی (`main`) یا ریشهٔ مخزن روی GitHub Pages میزبانی می‌شود:
1. فایل `CNAME` در ریشه قرار دارد و دامنه `daftrche.ir` را تنظیم می‌کند.
2. هیچ مرحله کامپایل یا بیلد نیاز نیست.
3. در تنظیمات مخزن در GitHub (بخش Pages)، منبع انتشار را روی ریشه (`/`) شاخه موردنظر قرار دهید.

## اصول فنی و سیاست امنیتی (CSP & Invariants)

تمام تغییرات در این پروژه ملزم به رعایت اصول سخت‌گیرانه زیر هستند:

1. **امنیت بدون سازش (Strict CSP):**
   سیاست امنیتی فقط منابع مبدأ خودی (`'self'`) را مجاز می‌داند:
   * هیچ اسکریپت یا استایل درون‌خطی (`inline script` یا `inline style`) وجود ندارد.
   * هیچ فونت، استایل یا کتابخانهٔ خارجی از طریق CDN مجاز نیست.
2. **بهبود پیش‌رونده (Progressive Enhancement):**
   صفحه بدون جاوااسکریپت نیز کاملاً خوانا، ساختاریافته و دارای لینک‌های کاربردی است. اگر جاوااسکریپت غیرفعال باشد، هیچ محتوایی مخفی نمی‌ماند.
3. **اعتبارسنجی و ایمن‌سازی ورودی‌ها:**
   پیوندها و هش‌های آدرس (`location.hash`) با بررسی مستقیم رشته‌ها مدیریت می‌شوند و بدون اعتبارسنجی وارد سلکتورها یا متدهای حساس نمی‌شوند.
4. **رعایت دسترس‌پذیری (Accessibility & a11y):**
   * تمامی عناصر تعاملی دارای استایل `:focus-visible` واضح هستند.
   * کنتراست متن‌ها حداقل نسبت ۴.۵ به ۱ را رعایت می‌کند.
   * در صورت فعال بودن `prefers-reduced-motion`، تمامی انیمیشن‌ها و ترنزیشن‌ها غیرفعال می‌شوند.
   * پشتیبانی کامل از حالت کنتراست بالا (`forced-colors: active`) و استایل‌های چاپ (`@media print`).
